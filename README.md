# Rocket Volley
Retro 3D 2v2 car volleyball in the Neon Meteor Dome: first to 7 wins.
Default controls: WASD drive, Space double-jumps, E dodges, Shift boosts, and C toggles cameras (gamepad supported).
Menus use W/S + Enter; remap controls and customize your car before entering the 3-2-1 serve countdown.
Download and run the .exe file to play
