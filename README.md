# Rocket Volley
Retro 3D 2v2 car volleyball: you and an AI teammate face two AI rivals; first to 7 wins.
Keyboard: WASD drive, Space jump/dodge, Shift boost, Esc pause; gamepad is supported.
Menus: W/S moves the > pointer, A/D changes styles, Enter selects, and [/] adjusts ball bounce.
Build with CMake 3.24+; dependencies are downloaded automatically on first configure.
