# Rocket Volley
Retro 3D 2v2 car volleyball in the Neon Meteor Dome: first to 7 wins.
Drive with WASD; Space double-jumps, S tilts nose-up for aerial boost, E dodges, Shift boosts, and C toggles cameras (gamepad supported).
Menus use W/S + Enter; customize body, wheels, and spoiler before entering the 3-2-1 serve countdown.
